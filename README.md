# Как выбрать шкафной кондиционер для промышленных электрошкафов

Практическое руководство по подбору для шкафов управления, телекома, батарей и модульных кабин.

Когда фон выше ~40°C, вентилятор недостаточен. **Закрытый контур** (компрессор, IP55) удерживает внутри 25–35°C и не пускает пыль/влагу.

## Подбор по объёму
- Малый (<2 м3): **3000 Вт**
- Средний (2–4 м3): **5000 Вт**
- Большой/контейнер (>4 м3): **7500 Вт**

## Важные характеристики
- IP55 для улицы и цехов
- Работа **от -40°C до +55°C**
- R410A + микроканальный теплообменник (~30% экономичнее)
- RS485/Modbus удалённый контроль
- от 52 дБ, обслуживание без инструментов
